# Security

Please report vulnerabilities privately to **support@paradigma.click** rather than in a public issue. Include the CLI version (`paradigma --version`), what you found and how to reproduce it. We will acknowledge your report and keep you updated until it is fixed.

In scope: this CLI, the skill and plugin manifests in this repository, and the Paradigma server endpoints the CLI talks to (`https://paradigma.click`). Please do not run automated scans against the server or access data that is not yours.

Never include real tokens, API keys or repository contents in a report.
